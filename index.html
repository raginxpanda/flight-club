SETUP / HOW IT WORKS
1. Collector account. Faction members SEND plushies and flowers to this player in Torn (Items → Send). This account's key runs the tracker.
2. Make the key. Torn → Settings → API Keys → custom key. For basic use pick only user: events, basic. To also auto-catch trades and market buys, add user: log and tick "deep capture" above. Never use a Full Access key. The key stays in this browser only and is sent only to api.torn.com.
3. Sync. Auto-sync pulls new incoming items every 60s while this tab is open, credits the sender at your rates, and adds to stock. Every event/log is processed once — re-syncing never double-counts.
4. The one manual step. Torn's API is read-only, so it can't send money. The ledger shows exactly who's owed what; you click "send" in-game and hit PAY here to clear the balance.
5. Going 24/7. This file only syncs while open. Pin the tab and it runs hands-off. For true always-on (polls even when your PC is off, can ping Discord), that needs a small hosted backend — ask and I'll build it.
6. Backup. Everything saves in this browser. EXPORT for a backup or to move devices (the key is never included in exports).
